## 📋 详细执行计划

### Phase 3.1 分批清理详细计划

#### 第一批: 核心编译器模块 (P0优先级)
**目标文件**: ~120个孤立.mli文件
**范围**: 
- `src/ast.mli`, `src/parser*.mli`
- `src/lexer*.mli`, `src/semantic*.mli`  
- `src/compiler*.mli`, `src/codegen*.mli`

**验收标准**:
```bash
# 自动化验收脚本
- 构建状态: dune build → 成功
- 测试状态: dune runtest → 100%通过
- 接口健康度: 核心模块 → 95%+ 匹配度
- 编译时间: 保持或改善当前基准
```

#### 第二批: 工具链和支持模块 (P1优先级)  
**目标文件**: ~130个孤立.mli文件
**范围**:
- `src/builtin*.mli`, `src/types*.mli`
- `src/error*.mli`, `src/formatter*.mli`
- `src/utils/*.mli`, `src/string_processing/*.mli`

#### 第三批: 扩展和实验性模块 (P2优先级)
**目标文件**: ~140个孤立.mli文件  
**范围**:
- `src/performance/*.mli`, `src/refactoring*.mli`
- `src/analysis*.mli`, `src/benchmark*.mli`
- 实验性功能和研究原型模块

### 风险管理与质量保证

#### 分级风险管理
- **Critical**: 编译系统失败 → 立即回滚机制
- **High**: 测试失败率 >5% → 暂停清理，问题诊断  
- **Medium**: 性能回退 >10% → 性能分析和优化
- **Low**: 文档不一致 → 文档更新和验证

#### 自动化质量门禁
```bash
# 每批清理后必须通过的检查
1. dune build --profile dev → 0错误0警告
2. dune runtest → 100%测试通过
3. 性能基准检查 → 编译时间<当前+10%
4. 接口完整性检查 → 关键API可用性确认
```
