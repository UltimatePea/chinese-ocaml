### ✅ 实施的修复方案

#### 1. OCaml版本兼容性修复
```ocaml
(* 修复前 - OCaml 5.x专用 *)
let temp_dir = Filename.temp_dir "ast_test" "dir" in

(* 修复后 - 4.14.x/5.x通用 *)
let temp_dir = Filename.temp_file "ast_test" "dir" in
let () = Unix.unlink temp_dir in
let () = Unix.mkdir temp_dir 0o755 in
```

**修复优势**:
- ✅ 向后兼容OCaml 4.14.x
- ✅ 向前兼容OCaml 5.x
- ✅ 功能行为完全一致
- ✅ 无破坏性变更

#### 2. Mutex模块路径修复
```ocaml
(* 修复前 *)
let cache_mutex = Thread.Mutex.create ()
Mutex.lock cache_mutex;

(* 修复后 *)
let cache_mutex = Mutex.create ()
Mutex.lock cache_mutex;
```

**技术说明**:
- OCaml 5.x中`Mutex`直接可用，无需通过`Thread`模块
- 移除了不必要的`threads`库依赖
- 保持线程安全性不变
