## 技术实现

### 清理命令
```bash
# 清理编译产物
find . -name "*.cmi" -delete
find . -name "*.cmo" -delete
find . -name "*.cmx" -delete  
find . -name "*.o" -delete

# 清理覆盖率文件
find . -name "*.coverage" -delete

# 清理构建缓存
dune clean
```

### 验证构建
