**实施计划**:

2. **统一数据模型设计** (Day 4-7)
   ```ocaml
   (* 设计统一韵律数据模型 *)
   type unified_rhyme_data = {
     tone_groups: tone_group list;

     validation_rules: validation_rule list;

   (* 标准化API接口 *)
   module UnifiedRhyme : sig
   ```

### 第二阶段: 编译器架构现代化 (10月1日-11月15日)

#### Phase 2.1: 长函数重构专项

**重构目标函数清单**:
1. `src/parser_core.ml` - 解析核心逻辑(预估80+行)
2. `src/token_conversion_unified.ml` - 令牌转换逻辑
3. `src/lexer.ml` - 词法分析状态机
4. `src/semantic.ml` - 语义分析核心函数

**重构标准**:
- 单个函数不超过50行（核心逻辑）
- 嵌套深度不超过4层
- 每个函数职责单一明确
- 保持功能完全一致

**重构方法论**:
```ocaml
(* 原始长函数重构示例 *)
let parse_expression_original lexer = 
  (* 80+行复杂逻辑 *)
  ...

(* 重构后模块化设计 *)
module ExpressionParser = struct
  let parse_primary lexer = ...     (* 15行 *)
  let parse_binary lexer = ...      (* 20行 *)
  let parse_unary lexer = ...       (* 12行*)
  
  let parse_expression lexer =      (* 25行主逻辑 *)
    let primary = parse_primary lexer in
    let binary = parse_binary lexer primary in
    parse_unary lexer binary
end
```
