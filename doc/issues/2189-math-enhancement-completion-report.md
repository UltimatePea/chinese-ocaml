### 📐 反三角函数技术实现

#### 1. 反正弦函数 (asin)
- **算法**: 泰勒级数展开
- **定义域**: [-1, 1] 
- **值域**: [-π/2, π/2]
- **精度**: 20项级数保证高精度
- **错误处理**: 定义域越界返回中文错误消息

```ocaml
asin(x) = x + x³/6 + 3x⁵/40 + 5x⁷/112 + ...
```

#### 2. 反余弦函数 (acos)  
- **算法**: acos(x) = π/2 - asin(x)
- **定义域**: [-1, 1]
- **值域**: [0, π] 
- **优化**: 复用asin实现，确保一致性

#### 3. 反正切函数 (atan)
- **算法**: 分段处理
  - 对于 |x| ≤ 1: 使用泰勒级数
  - 对于 |x| > 1: 使用恒等式 atan(x) = π/2 - atan(1/x)
- **定义域**: (-∞, ∞)
- **值域**: (-π/2, π/2)
- **收敛**: 30项级数确保收敛

### 🔢 欧拉φ函数实现

#### 数学原理
```
φ(n) = n * ∏(1 - 1/p) 对所有质因子p
```

#### 算法步骤
1. **质因数分解**: 获取n的所有不同质因子
2. **乘性公式**: φ(n) = n * ∏((p-1)/p)
3. **优化**: 避免重复质因子，提高计算效率

#### 验证示例
- φ(1) = 1
- φ(2) = 1  
- φ(6) = 2 (与2和6互质的数: 1,5)
- φ(9) = 6 (φ(3²) = 3² - 3¹ = 6)
