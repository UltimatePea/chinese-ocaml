### 标准化分类原则

#### 1. 按功能模块分类
- **core/**: 编译器核心功能测试
- **lexer/**: 词法分析专项测试
- **parser/**: 语法解析专项测试
- **semantic/**: 语义分析专项测试
- **codegen/**: 代码生成专项测试

#### 2. 按测试层级分类
- **unit/**: 单模块单元测试
- **integration/**: 多模块集成测试
- **regression/**: 回归测试用例

#### 3. 按特色功能分类
- **poetry/**: 诗词编程特色功能测试
- **builtin/**: 内置函数库测试
- **performance/**: 性能基准测试

#### 4. 按开发阶段分类
- **debug/**: 开发调试测试
- **experimental/**: 实验性功能测试

## 📋 测试文件命名规范

### 标准命名格式
```
test_<模块名>_<功能描述>_<覆盖级别>.ml
```

### 覆盖级别标记
- `_basic.ml`: 基础功能测试
- `_comprehensive.ml`: 全面覆盖测试
- `_enhanced.ml`: 增强功能测试
- `_coverage.ml`: 覆盖率专项测试
- `_performance.ml`: 性能专项测试

### 示例
```
test_lexer_chinese_tokens_comprehensive.ml
test_parser_expressions_basic.ml
test_semantic_type_checking_enhanced.ml
```
