# 骆言 — 中文OCaml语言

骆言是一门使用纯中文语法的函数式编程语言，编译为OCaml。

## 安装

```bash
opam install dune
dune build
dune install   # 安装 luo 命令
```

## 语法速览

### 标识符

所有用户定义的名称用角括号括起：

```
「变量名」   「函数名」   「参数」
```

> 提示：中文输入法下，`Ctrl+[` 和 `Ctrl+]` 可输入 `「` 和 `」`。

### 注释

```
「：这是一行注释：」
```

也支持OCaml原生注释：`(* ... *)`

### 绑定

```
让 「x」 = 42
让 递归 「阶乘」 「n」 =
  如果 「n」 = 0 那么 1
  否则 「n」 * 「阶乘」 （「n」 - 1）
```

### 函数（Lambda）

```
函数 「x」 → 「x」 + 1
函数 「x」 → 函数 「y」 → 「x」 + 「y」
```

### 条件

```
如果 「n」 > 0 那么 "正数" 否则 "非正数"
```

### 本地绑定

```
让 「y」 = 「x」 + 1 在
「y」 * 「y」
```

### 模式匹配

```
匹配 「值」 与
| 0 → "零"
| 「n」 → Printf.sprintf "其他：%d" 「n」
```

### 类型定义

```
类型 「颜色」 =
  | Red
  | Green
  | Blue
```

> 注意：构造子必须以大写字母开头（OCaml规范）。

### 列表与括号

| 骆言 | OCaml |
|------|-------|
| `（表达式）` | `(表达式)` |
| `【1；2；3】` | `[1;2;3]` |
| `「x」 :: 「xs」` | `x :: xs` |

### Unicode 运算符

| 骆言 | OCaml |
|------|-------|
| `→` | `->` |
| `←` | `<-` |
| `≤` | `<=` |
| `≥` | `>=` |
| `≠` | `<>` |
| `。` | `;;` |

## 使用示例

```
「：你好世界：」

让 （） = print_endline "你好，世界！"
```

运行：

```bash
luo 你好.ly
```

查看生成的OCaml代码：

```bash
luo --print 你好.ly
```

编译为可执行文件：

```bash
luo --compile 程序.ly
```

## 文件扩展名

骆言源文件使用 `.ly` 扩展名（骆言 = Luoyan）。

## OCaml互操作

由于骆言直接转译为OCaml，所有OCaml标准库函数均可直接使用。
ASCII标识符（如 `print_endline`、`List.map`）原样传递给OCaml编译器。
