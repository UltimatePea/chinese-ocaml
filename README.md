# 骆言

骆言是一个将中文语法转译为 OCaml 的**纯词法转换器**。它没有语法解析阶段——源文件逐字符扫描，每个词法单元直接替换为对应的 OCaml 词元，生成的 `.ml` 文件交给 OCaml 编译器处理。

## 快速开始

```bash
dune build
dune exec bin/main.exe -- 示例/你好.ly          # 运行程序
dune exec bin/main.exe -- --print 示例/你好.ly  # 查看生成的 OCaml
dune exec bin/main.exe -- --ast   示例/你好.ly  # 查看词法单元流
dune test                                        # 运行测试套件
```

## 词法规则

### 标识符 `「名称」`

用户定义的名称用角括号括起。中文名称编码为 `luo__` 加 UTF-8 十六进制字节；纯 ASCII 名称原样输出。

```
「变量」   →   luo__e58f98e9878f
「x」      →   x
「Node」   →   Node
```

### 注释 `「：内容：」`

```
「：这是一行注释：」   →   (* 这是一行注释 *)
```

也支持 OCaml 原生注释 `(* ... *)` 原样保留。

### 字符串 `『内容』`

```
『你好，世界！』   →   "你好，世界！"
```

双引号在内容中自动转义为 `\"`。

### 原生 OCaml `《代码》`

内容**原样输出**，用于嵌入标准库绑定或无法用骆言表达的代码。

```
《List.map》   →   List.map
《Printf.printf》   →   Printf.printf
```

### 模块访问 `之`

```
「输出」之「行」   →   Luo__...输出.luo__...行
```

`之`（U+4E4B）专用于模块成员访问，不参与关键字或标识符匹配。

### 导入 `引入 『路径.ly』`

读取指定文件，递归转译后内联展开，路径相对于当前文件目录。

```
引入 『../骆言/输出.ly』
```

## 构造子命名

在类型定义和模式匹配中，`案 「名称」` 将该名称注册为构造子。注册后，该名称在任何位置均使用 `Luo__` 前缀（大写，满足 OCaml 构造子命名要求）。

```
类型 「形状」 是
  案 「圆」 的 浮点数
  案 「矩形」 的 浮点数 乘 浮点数

匹配 「s」 与
案 「圆」 「r」 则 ...
案 「矩形」 「w」 「h」 则 ...
```

---

## 仅使用 ASCII 的字符

骆言中，非中文字符只允许出现在以下情形：

- 配对定界符：`（）`、`【】`、`「」`、`『』`、`《》`
- 中文标点：`、`（顿号）、`。`（句末全停）
- 原生 OCaml 算术和比较运算符直接写 ASCII：`+`、`-`、`*`（或用 `乘`）、`/`、`<`、`>`、`<=`、`>=`、`<>`、`=`、`!`、`::`、`;` 等

## 标准库

`骆言/` 目录提供用骆言自身编写的标准库，通过 `《》` 嵌入 OCaml 原语：

| 文件 | 内容 |
|------|------|
| `骆言/输出.ly` | 终端输入输出（`行`、`打印`、`格式`…） |
| `骆言/列表.ly` | 列表操作（`映射`、`左折`、`过滤`…） |
| `骆言/基础.ly` | 比较、引用、类型转换 |
| `骆言/字符串.ly` | 字符串操作 |
| `骆言/数组.ly` | 数组操作 |

## 完整示例

```
引入 『骆言/输出.ly』
引入 『骆言/基础.ly』

类型 「树」 是
  案 「叶」
  案 「节」 的 「树」 乘 整数 乘 「树」

让 递归 「深度」 「t」 是
  匹配 「t」 与
  案 「叶」 则 0
  案 「节」 （「左」、空、「右」） 则
      1 + 「最大」 （「深度」 「左」） （「深度」 「右」）

让 「树」 是
  「节」 （「节」 （「叶」、1、「叶」）、2、「叶」）

让 （） 是
  「输出」之「格式」 『深度：%d\n』 （「深度」 「树」）
```
